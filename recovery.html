Recovery Workflow

How SHIELD-Chain is intended to handle a suspicious file change.

Step 1: Detect an unexpected file change.
Step 2: Verify the file's integrity and review the security event.
Step 3: Identify a trusted backup, if available.
Step 4: Obtain authorization before restoring the file.
Step 5: Record the recovery result in the security event history.
